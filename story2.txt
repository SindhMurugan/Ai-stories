PART 1: HOW TO USE THIS FILE (READ FIRST)
------------------------------------------------------------------

1. Make the 5 reference images first (PART 2). Do this before any scene.
2. Save each reference image to one folder on your computer, with clear names:
     01_PomegranateAmma.png
     02_BlueberryChild1.png
     03_BlueberryChild2.png
     04_BananaHusband.png
     05_GuavaSecondWife.png
3. For each scene in PART 3:
   a. Copy the whole block from the line that starts with "PROMPT START"
      to the line that says "PROMPT END". Copy it exactly, including the
      Character Bible. Do not shorten or retype it.
   b. Open Google Flow and start a new generation.
   c. Paste the prompt into the text box.
   d. Attach the reference images listed under "Attach these reference
      images" for that scene. Attach them in the same order every time.
   e. Generate. Save the best take as SCENE_01.mp4, SCENE_02.mp4, and so on.
4. When all 8 clips are done, join them in order (Scene 1 to Scene 8)
   in the Flow editor or any video editor.

Tip: Keep one note file open with the take numbers you chose, so you
always know which one is final.

PART 5: LIP SYNC AND CONSISTENCY CHECKLIST
------------------------------------------------------------------

LIP SYNC
- Each dialogue line is short (under about 12 words) so it fits in 8 seconds.
- Each line names one speaker. Keep the speaker names exactly as written.
- Generate each scene 2 or 3 times. Choose the take where the mouth
  movement matches the words best.
- If Tamil lip-sync looks wrong, shorten that line first. Shorter lines
  usually work better. You can also switch that one line to English
  and keep the same speaker description.
- Never add extra dialogue to a scene. More speech means worse sync.

CHARACTER CONSISTENCY
- Attach the SAME reference image for each character in every scene
  where they appear. Use the saved files from PART 2 only.
- Keep the attached images in the same order in every scene.
- Do not edit or retype the CHARACTERS block. Copy it exactly.
- If a character drifts (wrong color, missing crown, wrong clothes),
  regenerate that scene with the reference image attached again.
- Flow has no exact seed setting, so consistency comes from reference
  images plus identical text. Check every take against PART 2 before
  you keep it.
- Keep NO human features in any image or clip. If a human appears,
  regenerate with "no human characters, no human faces" at the start.

FINAL CHECK BEFORE JOINING CLIPS
[ ] All 5 reference images saved and named correctly
[ ] Scene 1 to Scene 8 each generated and saved in order
[ ] Each scene has its listed reference images attached
[ ] Pomegranate Amma: pomegranate color, gold crown, saree (same in every clip)

[ ] Banana husband: yellow banana, black clothes (same in every clip)
[ ] Guava wife: pink-green guava, red dress (same in every clip)
[ ] No human faces or human characters anywhere
[ ] Lip movement matches dialogue in each clip
[ ] Clips joined in order, Scene 1 to Scene 8
